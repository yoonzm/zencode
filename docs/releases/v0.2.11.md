## 更新内容

- 调整 Windows 本地 nginx 验证指令：服务启动与 HTTP 就绪探测分别执行，减少复合 PowerShell 脚本被命令策略误判的机会。
- 保持完全访问模式的 `danger-full-access + never` 配置，已授权的构建、服务启动和测试不逐条请求执行许可；需求、环境或验收标准不明确时仍可向用户澄清。
- 区分命令策略拒绝与 nginx 运行失败，记录真实拒绝原因，避免盲目重试或错误报告验证通过。本次优化任务指令，不关闭 Codex 的独立命令策略检查。

## Changes

- Run Windows nginx startup and HTTP readiness probes as separate operations to reduce conservative policy matches on compound PowerShell scripts.
- Preserve `danger-full-access + never` without per-command permission prompts, while allowing clarification of ambiguous requirements, environments and acceptance criteria.
- Distinguish command-policy rejections from nginx runtime failures and preserve truthful verification results. This update improves task instructions; it does not disable Codex command-policy checks.
