## 更新内容

- 产品需求统一为一个任务工作区，可关联多个仓库，并在原有 Merge Request 上继续修改和提交。
- 使用共享 Git 仓库池和独立 worktree，复用仓库历史，保留各任务独立的工作文件、索引和分支；支持 Windows 长路径。
- 降低并发任务资源开销：合并差异扫描、批量刷新和保存流式消息、复用未变化的补丁解析结果，限制仓库检出及验证阶段的并发。
- 修复点击停止时出现 `no active turn to interrupt` 的竞态问题，保留工作区改动及待执行指令。
- 修复飞书完成通知中变动文件数始终为 0 的问题，直接根据后端 Git 差异统计。
- 展示实时验证进度，支持点击验证目标链接，切换任务页签时保留输入草稿。
- 统一图片预览，支持缩放、拖动和切换；记住任务筛选及状态分组展开设置。
- 增加项目专有提示词，改进任务对话和多仓库工作区入口。

## Changes

- Unify product requirements into one workspace with multiple repositories, and continue revisions in the existing merge request.
- Reuse Git history through a shared repository pool and isolated task worktrees, including Windows long-path support.
- Reduce concurrent task overhead with coalesced background diffs, batched streaming updates and checkpoints, cached patch parsing, and separate checkout/verification capacity limits.
- Fix cancellation races and Feishu changed-file totals while preserving edits and queued instructions.
- Improve live verification progress, target links, conversation drafts, project instructions, image previews and persisted task-list preferences.
