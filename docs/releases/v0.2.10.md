## 更新内容

- 补回禅道「同步类型」设置，可选择「只同步 BUG」「只同步需求」或「BUG 和需求」，与负责人范围、已映射产品范围组合生效。
- 后端跳过未选中类型的列表和详情请求，避免把仅用于显示的筛选误当成同步限制。
- 保存同步类型并在重启后恢复；旧配置缺少该字段时默认同步两类。调整设置不会删除已进入执行流程的任务。

## Changes

- Add the missing ZenTao sync-type selector for bugs, requirements, or both, combined with assignee and mapped-product scope.
- Skip API requests for excluded task types instead of only filtering the visible list.
- Persist the selection across restarts and preserve the existing both-types behavior for older configurations. Tasks already in the execution workflow remain available.
