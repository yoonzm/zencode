## Changes

- Show real verification screenshots in the Verification tab, with thumbnails, an enlarged preview, and keyboard navigation. Existing task evidence directories are supported.
- Exclude `.verification` screenshots, logs, and temporary scripts from code diffs, file counts, and new MR commits while keeping the evidence locally.
- Load Codex models and reasoning levels from the local model catalog, and reuse a shared isolated headless Playwright runtime.
- Improve task deletion progress, background workspace cleanup, stop/continue controls, queued messages, and task ordering.
- Add Feishu notification settings and system-tray operation; update repository mapping and composer controls.

## 更新内容

- 验证 Tab 展示真实截图，支持缩略图、放大预览和方向键切换，兼容已有任务的证据目录。
- `.verification` 中的截图、日志和临时脚本不再计入代码变更、文件数及新 MR 提交，本地证据仍保留。
- 从本地 Codex 加载模型与思考强度，共用隔离的 Playwright 无头验证运行环境。
- 改进删除进度、后台工作区清理、停止与继续、排队消息和任务排序。
- 增加飞书通知和系统托盘运行，更新仓库映射与输入区交互。
